## About Me

I am a Software Engineer working at the intersection of backend engineering, cybersecurity, and AI engineering, with a focus on digital forensics and applied AI systems over shallow AI-wrapper work. Currently interning at **Northern Trust** as an Infrastructure SDE with the SRE team, and pursuing a B.Tech in Cyber Security and Forensics. Portfolio at [ashishcodes.com](https://ashishcodes.com)

### Focus Areas
- **AI-Driven Digital Forensics** — Building investigative and evidence-extraction platforms using RAG, LLMs, and automated reporting pipelines.
- **Security & Cryptography** — Engineering zero-knowledge encryption architectures, steganography toolkits, and secure backend systems.
- **Backend & Infrastructure** — Building REST APIs and platform tooling, and working with observability stacks (Dynatrace, DQL) in production environments.

## Featured Projects

### [Omniscient](https://github.com/ASHISH9925/Omniscient) — AI-Powered Risk Intelligence & Data Aggregation Platform
*An AI-driven digital forensics platform automating social media evidence extraction, analysis, and investigative reporting.*

Engineered the backend and a LangChain + LLaMA 3.2 (RAG) investigative chatbot enabling context-aware querying and automated PDF/CSV forensic report generation.

### [Obscura](https://github.com/ASHISH9925/Obscura) — Zero-Knowledge File Encryption Platform
*A zero-knowledge encryption architecture where servers persist only ciphertext.*

Designed in-memory key isolation with UUID-based access control, plus an authenticated encryption workflow with steganographic key delivery via PNG images.

### [StegoCrypt](https://github.com/ASHISH9925/StegoCrypt) — Image Encoding & Data-Hiding Toolkit
*Pixel-level image steganography via RGB bit-plane manipulation.*

Implemented the LSB algorithm balancing payload capacity and imperceptibility, with a secure Flask backend and React frontend for uploads and async processing.
